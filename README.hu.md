Egy személy tájékoztató jellegű tudományos profilja, helyben számolva: biológiai életkor (PhenoAge), hang, kézírás, órarajz-teszt, személyiség (TIPI) és reakcióidő.

## Funkciók

- PhenoAge biológiai életkor, hihetetlen laborértékekre védelemmel.
- Hangelemzés oktávugrás-szűréssel, grafometria, órarajz- és emberrajz-teszt.
- TIPI személyiség, reakciótesztek, nyomtatható jelentés, JSON export/import és módszertan fül.

## Használat

Nyisd meg az oldalt online, vagy töltsd le az `index.html` fájlt és nyisd meg egy friss böngészőben. Telepítés és build nélkül.

## Korlátok

- Oktató jellegű szűrőeszköz, nem diagnózis; ne használd orvosi, munkahelyi vagy jogi döntésekhez.
- Magadon vagy a vizsgált személy tájékozott beleegyezésével használd.
- A felület egyelőre csak románul érhető el.

## Adatvédelem

Nincs követés, nincs hálózati kérés (CSP `connect-src none`), nincs fiók. Az adatok ebben a böngészőben maradnak (localStorage), és bármikor törölhetők.
